# 🏢 피클 합동 비서실

피클(Pickle)들이 함께 일하는 귀여운 2D 사무실입니다.
로그인 없이 링크만 열면 들어올 수 있고, 채팅·업무 보드·아바타가 실시간으로 함께 움직입니다.

**바로 열기 →** https://egofml.github.io/pickle-office/

## 쓰는 법

1. 사무실에 들어와 내 피클 이름·자음·색을 고릅니다 (기본: 크리 ㅋ 베이지).
2. 오른쪽 위 **👥 피클 초대하기**에서 링크를 복사해 친구에게 보냅니다.
3. 링크를 연 친구는 자기 피클만 정하면 같은 사무실에 도착합니다.

- 말 걸기: 채팅에서 `@이름`, 또는 사무실의 아바타(근처)를 클릭
- 구역 이동: 사무실의 **작업실 / 회의실 / 라운지** 라벨을 클릭 (모바일은 오른쪽 위 구역 버튼)
- 업무 보드: 할 일을 적고 담당(@이름)을 정하면 완료율이 함께 올라갑니다
- 낮/밤 테마, 내 피클 꾸미기(설정 ⚙️)

## 동작 방식

- 대화·업무는 이 기기에 저장되고(localStorage), 같은 방 코드를 연 사람끼리 공개 MQTT 중계 서버(WebSocket)로 실시간 공유됩니다. 계정을 만들지 않습니다.
- 처음 열면 이 기기 전용 방 코드(`office-xxxxx`)가 자동으로 생기고 주소에 붙습니다. 다른 기기에서 이어 쓰려면 초대 링크를 쓰세요.
- 설정에서 **Firebase RTDB 주소**를 직접 넣으면 그 DB로도 동기화할 수 있습니다.
- 공개 중계 서버를 거치므로 민감한 내용은 올리지 마세요.

## 배포

GitHub Pages(브랜치 `gh-pages`, 루트). `main`의 내용을 `gh-pages`로도 밀어 배포합니다.

    git push origin main && git push origin main:gh-pages

`.nojekyll` 포함. 외부 라이브러리는 Pretendard(폰트), mqtt.js(WebSocket)만 CDN에서 불러옵니다.
